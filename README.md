# AI-Psychologist

Modern AI-powered therapist chat application with a clean conversational interface inspired by modern AI platforms and focused on smooth user experience.

## Features

- AI-powered conversational interface
- Real-time chat interaction
- Modern responsive UI
- Smooth message animations
- Clean typography and layout
- Mobile-friendly design
- Minimalist dark-themed interface
- Fast and lightweight frontend structure

## Technologies

- HTML5
- CSS3
- JavaScript
- AI API Integration

## Functionality

- Real-time AI conversations
- Dynamic message rendering
- Responsive chat layout
- Interactive user experience
- Conversation-focused interface design

## Goals

This project was created to explore AI integration, modern chat UI development, responsive frontend architecture, and interactive web application design.
